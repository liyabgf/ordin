# 长期方向（参考，不是当下目标）

> 这份文档记录的是**完整项目目标**，用来校准方向，**不用来安排当下的工作**。
> 当下目标只有一件事：[脱离 DSH、独立运行](01-current-goal.md)。

## 四层结构

```
人
意图、决策、监督
        ↕
个人数字人格
身份 · 长期记忆 · 上下文 · 行为连续性
        ↕
Ordin（原 ordin）                手机操作端
任务组织、授权、调度、监督          APP、通知、设备功能、现实交互
        ↕
现实世界
信息、服务、应用、设备与外部环境
```

## Ordin 在其中的位置

Ordin 是**任务层**：把人的意图变成有授权、有记录、可监督的执行，并把结果送回去。
它上面是"我是谁、我记得什么"（数字人格），旁边是"我在手机上怎么碰世界"（操作端），
下面是"活到底干成什么样"（现实世界）。

## 明确不属于当下范围

- 个人数字人格（身份、长期记忆、行为连续性）——长期方向，当前仓库不建
- 手机操作端 App、设备功能调用——长期方向，当前只做已有的聊天桥与通知
- 多用户身份与权限体系——与 ordin 一致，是当前发布阻塞项，不在独立化阶段顺带解决

## 当下与长期的关系

独立化是长期方向的地基：只有 Ordin 自己是独立进程、执行单元可插拔，
上面的数字人格和旁边的手机端才有稳定的"任务层"可以依靠。
所以当下把独立做扎实，就是在为这张图铺路；**但不要提前建图里的其他层**。
